# xenagarage.github.io
All content that will be provided open on Xena Garage.

This is the first message of XenaGarage Pages.

## Writing a post

- New post: add `_posts/YYYY-MM-DD-some-title.md` with front matter (`layout: post`, `title`, optional `subtitle` and `tags`), then push. GitHub Pages rebuilds in about a minute.
- Drafts go in `_drafts/` (no date in the filename). They aren't published until you move them to `_posts/`.
- Local preview: `bundle install && bundle exec jekyll serve --drafts`, then open http://localhost:4000

Design: one CSS file (`assets/css/style.css`), Inter + JetBrains Mono, safety-orange accent, automatic dark mode.
